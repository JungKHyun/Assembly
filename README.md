# 국회 요구자료 대응 도구

국회 요구자료를 문항 단위로 접수하고, 배분기준표에 따른 소관 과 후보를 확인해 담당자가 배분을 확정하도록 돕는 교육용 웹 도구입니다. 현재는 **접수·문항 분해·배분·현업 회신·재배정 요청**을 구현했으며, 취합 기능은 아직 구현되지 않았습니다.

## 사용해 보기

- [시작 화면](https://assembly-neon.vercel.app/)
- [접수·배분 화면](https://assembly-neon.vercel.app/assign.html)
- [현업 회신 화면](https://assembly-neon.vercel.app/dept.html)

Vercel 접근 보호가 적용되어 로그인 화면이 표시될 수 있습니다.

## 현재 제공 기능

- PDF 자료요구서를 브라우저에서 읽어 문항 단위로 분해
- 문항목록 CSV 불러오기
- 배분기준표에 따라 후보 과 최대 3순위와 근거 표시
- 조직도에 등록된 과만 배분 대상으로 제공
- 담당자가 주관·협조 과를 선택하고 배분을 확정
- 내 과 문항의 회신 엑셀·메모 제출과 재배정 요청
- 1순위 근거 키워드 기준 과거 520건의 배분 이력 표시
- 접수 및 배분 현황 확인, 검색·상태 필터, 브라우저 저장 자료 초기화

## 로컬 실행

Python 3가 설치된 환경에서 저장소 루트에서 정적 웹 서버를 실행합니다.

```bash
python -m http.server 8000 -d web
```

브라우저에서 <http://localhost:8000>을 엽니다. PDF.js와 배분 기준 자료가 함께 제공되므로 로컬 파일을 더블클릭하는 대신 HTTP 서버로 실행해야 합니다.

## 데이터 및 개인정보

`*.vercel.app`에서는 서버 함수와 Vercel Blob을 통해 공유 저장하고, 그 밖의 주소에서는 현재 브라우저의 `localStorage`에 저장합니다. PDF는 브라우저 안에서 처리합니다. 브라우저 저장 자료를 초기화해도 원본 PDF와 CSV 파일은 삭제되지 않습니다.

저장소의 자료는 교육용 가상 자료입니다. 실제 요구자료나 개인정보를 이 도구 또는 외부 AI 서비스에 입력하지 마세요. 현재 버전에는 사용자 인증·권한 관리가 없으므로 업무상 민감한 자료를 처리하는 운영 시스템으로 사용하지 마세요.
