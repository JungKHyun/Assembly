# 브라우저 라이브러리

이 폴더의 외부 라이브러리는 인터넷 연결 없이 화면에서 실행하도록 고정 버전으로 보관한다.

| 파일 | 라이브러리 | 버전 | 용도 |
|---|---|---:|---|
| `papaparse.min.js` | Papa Parse | 5.5.3 | CSV 읽기 |
| `xlsx.full.min.js` | SheetJS Community Edition | 0.18.5 | 엑셀 읽기·내보내기 |
| `chart.umd.min.js` | Chart.js | 4.5.1 | 처리 상태 차트 |
| `fuse.min.js` | Fuse.js | 7.1.0 | 유사 문항 검색 |
| `tabulator.min.js`, `tabulator.min.css` | Tabulator | 6.3.1 | 정렬 가능한 최근 문항표 |
| `pdf.min.mjs`, `pdf.worker.min.mjs` | PDF.js | 6.5.438 | 브라우저 안에서 PDF 읽기 |

각 배포 파일에 포함된 저작권·라이선스 고지를 유지한다. PDF.js의 별도 고지는 `pdfjs-LICENSE.txt`에 있다.
